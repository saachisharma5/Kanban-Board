# 📋 Kanban Task Manager

A simple Kanban board built using **HTML, CSS, and Vanilla JavaScript** to manage daily tasks. The application allows users to create tasks, organize them using drag-and-drop, and automatically saves everything in the browser using Local Storage.

This project was built to strengthen my understanding of DOM manipulation, event handling, drag-and-drop functionality, and browser storage without using any frameworks.

---

## 🚀 Features

* Create new tasks with a title and description
* Drag and drop tasks between **To Do**, **In Progress**, and **Done**
* Delete tasks
* Live task count for each column
* Tasks remain saved even after refreshing the page
* Simple modal for adding new tasks
* Basic input validation
* Clean and responsive interface

## ⚙️ How It Works

1. Click **Add New Task**.
2. Enter a task title and description.
3. The task is added to the **To Do** column.
4. Drag the task to **In Progress** or **Done** as work progresses.
5. Delete tasks when they are no longer needed.
6. All tasks are automatically stored in Local Storage.
